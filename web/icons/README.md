# The icons Overlook ships

Logos for common apps and tools, from
[homarr-labs/dashboard-icons](https://github.com/homarr-labs/dashboard-icons)
(Apache-2.0, `LICENSE-dashboard-icons`), but for two, outside that licence:

- `unifi.png`, Ubiquiti's own: the square favicon of account.ui.com, where
  unifi.ui.com signs in (`static/apple-touch-icon.png`).
- `checkmate.svg`, Checkmate's own, from its repository
  (`client/public/checkmate_favicon.svg`): a king Checkmate adapted, by
  colouring its outline green, from
  [Chess klt45.svg](https://commons.wikimedia.org/wiki/File:Chess_klt45.svg)
  by Cburnett, under
  [CC BY-SA 3.0](https://creativecommons.org/licenses/by-sa/3.0/), which it
  stays under.

Each logo remains its owner's trademark. Name one in the config's `icon:`,
or put your own in `icons/` beside the config, where it wins over one of
the same name here.
