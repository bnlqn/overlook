# The icons Overlook ships

Logos for common apps and tools, from
[homarr-labs/dashboard-icons](https://github.com/homarr-labs/dashboard-icons)
(Apache-2.0, `LICENSE-dashboard-icons`). Each logo remains its owner's
trademark. Name one in the config's `icon:`, or put your own in `icons/`
beside the config, where it wins over one of the same name here.
